Base para manifest.php que el visor usará. Vacío = misma URL del sitio. Las firmas de objetos .dcm siguen usando Custom Domain si está configurado.
Instance: Stream en memoria (rápido pero muchos requests). ZIP: Comprime todo en un archivo. Pre-Download: Descarga a disco primero, luego sube. ZIP-Extract-Upload: Descarga ZIP desde Orthanc, extrae localmente, sube con workers persistentes (reutiliza conexiones).
Carpeta donde se guardan temporalmente los ZIPs antes de subirlos a R2. Se eliminan automáticamente después del upload.
