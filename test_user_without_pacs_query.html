Instrucciones de Prueba
  1. Abrir dashboard-unified.html en otra pestaña
  2. Verificar el modo que se activa automáticamente
  3. Comprobar las funcionalidades disponibles según el permiso
  4. Usar estudios-manager.html para asignar estudios a usuarios sin PACS QUERY
Cómo funciona el sistema:
  • Con PACS QUERY: El usuario puede buscar cualquier estudio en el servidor PACS usando filtros de fecha, paciente, modalidad, etc.
  • Sin PACS QUERY: El usuario solo ve estudios que le han sido específicamente asignados por un administrador desde estudios-manager.
  • Asignación: Los administradores buscan estudios en PACS y los asignan a usuarios específicos.
