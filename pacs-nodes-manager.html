    PACS Cloner

    Réplica controlada hacia Orthanc local (C-MOVE vía el mismo flujo que Jobs). Las políticas guardan criterios para el daemon futuro; hoy puede encolar recuperaciones y ver el historial de órdenes.

    Migraciones: migration_pacs_cloner.sql, migration_pacs_cloner_alignment_strategy.sql, migration_pacs_cloner_discovery_sort.sql y opcional migration_pacs_cloner_worker.sql. El daemon es el script CLI modules/pacs-nodes-manager/bin/cloner-worker.php (cron/systemd); las políticas deben tener modo automatic y activa. El motor alternativo cloner-worker-v2.php es independiente y viene desactivado en base de datos hasta que lo habilite abajo.
    Workers CLI (cron)

    Por defecto solo el v1 corre si el cron llama a cloner-worker.php. El v2 requiere otra entrada en cron y el flag activo; no sustituye al v1 salvo que usted desactive el v1 o cambie el cron.
