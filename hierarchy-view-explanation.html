Vista de Jerarquía - ¿Para qué sirve?

Propósito Principal

La vista de jerarquía es una previsualización visual que muestra cómo quedará la estructura jerárquica cuando asignes un nuevo padre a un usuario.

Funciones Principales

Previsualización Visual

Muestra la estructura padre-hijo antes de guardar los cambios

Información Detallada

Incluye nombres, emails, niveles y badges de cada usuario

Advertencias

Alerta si el usuario tiene dependientes que también se moverán

Actualización Dinámica

Cambia automáticamente cuando seleccionas un padre diferente

Beneficios

Prevención de Errores

Evita asignaciones incorrectas al mostrar el resultado antes de guardar

Claridad Visual

Representación gráfica fácil de entender de la jerarquía

Información Completa

Muestra todos los datos relevantes de padre e hijo

Feedback Inmediato

Respuesta instantánea a los cambios en la selección

Demostración Interactiva

Selecciona diferentes opciones para ver cómo cambia la vista de jerarquía:

Vista de Jerarquía:
Usuario independiente
Sin padre asignado
Casos de Uso
  • Asignar Padre: Ver cómo quedará la relación padre-hijo
  • Cambiar Padre: Previsualizar la nueva estructura
  • Remover Padre: Confirmar que el usuario será independiente
  • Validar Jerarquía: Evitar ciclos o estructuras incorrectas
Advertencias Mostradas
  • Dependientes: Si el usuario tiene hijos, se muestra cuántos se moverán
  • Herencia: Los estudios asignados se heredarán automáticamente
  • Permisos: Se mantienen los permisos del usuario
Resumen

La vista de jerarquía es una herramienta de previsualización y validación que te permite ver exactamente cómo quedará la estructura jerárquica antes de confirmar los cambios, evitando errores y proporcionando claridad visual sobre las relaciones padre-hijo.
