⚙️ Configuración de Envío a PACS

Configura el formato por defecto que se usará al enviar informes a Orthanc PACS desde Informes Manager

ℹ️ Esta configuración se aplicará a TODOS los envíos futuros desde Informes Manager.

Formato por Defecto

📄

PDF

Documento con texto seleccionable y copiable

Recomendado
🖼️

PNG / Imagen

Imagen compatible con todos los visores DICOM

Universal

ℹ️ ¿Qué significa esta configuración?

  • Esta configuración define qué formato se usará automáticamente al enviar informes desde Informes Manager
  • No necesitarás elegir el formato cada vez, se usará el que configures aquí
  • Puedes cambiar esta configuración en cualquier momento
  • La configuración se guarda en la base de datos y aplica para todos los usuarios

✅ Cuándo usar cada formato:

  • PDF: Informes con texto que necesites copiar, imprimir o archivar
  • PNG: Cuando necesites máxima compatibilidad con todos los visores DICOM
