Puntuación Básica:
  • "punto" → .
  • "coma" → ,

  • "punto y coma" → ;

Formato Especial:
  • "punto aparte" → Nuevo párrafo
  • "nueva línea" → Salto de línea
  • "párrafo nuevo" → Doble salto
Unidades Médicas:
  • "milímetros" → mm
  • "centímetros" → cm
  • "kilogramos" → kg
  • "grados celsius" → °C
  • "por ciento" → %
  • "más menos" → ±
Comandos de Edición:
  • "mayúscula [texto]" → TEXTO
  • "minúscula [texto]" → texto
  • "borrar" → Elimina comando
  • "deshacer" → Ctrl+Z
También puedes usar variaciones como "pon punto", "agrega coma", etc.

Cómo usar la Grabación Sincronizada
Funciones principales:
  • Iniciar SYNC: Graba audio y transcribe simultáneamente
  • Transcripción automática: El texto aparece en tiempo real y se inserta en el editor
  • Navegación por palabras: Haz clic en cualquier palabra para reproducir esa parte del audio
  • Modos de reproducción: Continuo (reproduce desde la palabra) o Individual (solo esa palabra)
  • Panel de debug: Presiona Ctrl+Shift+D para ver información detallada
